1 · 全局运行骨架

启动时先弹模式选择窗口，选完才进游戏；三种模式共用同一个主循环。

  • 两层状态机：g_appMode 决定每帧推什么，g_netPhase 记录联机走到哪一步（握手 / 大厅 / 对局 / 断线）。
  • 菜单模式只 Sleep(10)：窗口隐藏、不推进游戏；选完模式要重置 prev/accumulator，否则把发呆时间算进第一帧。

2 · 一帧里发生什么 + 固定 60Hz 累加器

主循环每帧固定顺序做 6 件事；逻辑用累加器按 1/60 秒一格推进，与真实帧率解耦。

  • 确定性 + 联机对账：主机的 g_net.tick 是双方共用的时间轴，tick 步长必须恒定。
  • 为什么夹 dt：拖动标题栏会卡住主循环，不夹会松手后连环快进；联机下快进 120 tick 会挤爆发送缓冲。
  • 为什么 QPC：GetTickCount 精度 15.6ms 比一帧还粗，画面会抖。

3 · SimulateTick：一次逻辑推进的固定顺序

本地双人、主机联机共用这一段代码；顺序本身就是规则的一部分。

4 · 状态表与代码职责

整个程序就是「几张表」加「几件事」：所有函数都拿全局数据算一下。

关键函数作用
TileIsWall格子是不是墙；砖墙 'B' 和钢墙 '#' 对「能否通过」完全一样，越界视作墙
BoxHitsWall全场调用最频繁：判断一个方块有没有压到墙；-0.001f 避免贴边界误判
MoveTankX、Y 逐轴分离检测，被挡的轴不动、另一轴照走，实现贴墙滑行
Fire / BulletProbe / BulletHitCheck开火 → 探测撞了什么 → 每步查有没有打中坦克
HurtTank唯一伤害入口：扣血、阵亡给对手 +1、清空道具、36 分结束回合
DamageBrick砖墙 4 点血，归零就把字符改回 '.'，阻挡 / 绘制 / 命中自动一起失效
PickItem唯一写 weapon / ammo / mines / bricks 的地方；收不下返回 0，球留在地上
NetPoll / EncodeSnapshot / DecodeSnapshot轮询收发、打包全量状态、校验后整块覆盖客户端状态

5 · 重点链路：一次开火 → 一次自伤

文档里最需要推导的 80 行；三层结构（切子步 / X·Y 分判 / 同步反转 stepx）全在这里。

  • 出生点为什么是 12px：命中阈值 9+3=12，子弹刚好卡在判定边界；推到 15px 会生在墙里被判撞墙消失，所以改用 0.08 秒出膛保护。
  • 为什么 X、Y 分开判：只有分开才知道撞的是竖直面（翻 x）还是水平面（翻 y）；撞内角两轴都翻，原路返回。
  • 最容易漏的一行：stepx = -stepx；只翻 vel.x 的话，本帧剩余子步仍按旧方向推进，子弹会穿进墙里。

6 · 道具与四种特殊武器

规则差得太远，所以四种武器谁都不复用子弹；但伤害最后都汇到同一个入口。

  • 阵亡清空放在 HurtTank：被子弹、激光、追踪弹、地雷打死或自杀都必经这里，只清一次就够。
  • 追踪弹穿墙不是特判：飞行分支里根本没调用 BoxHitsWall，是「没写碰撞」。
  • 砖墙打穿只是把字符改回 '.'：阻挡、绘制、命中三处自动跟着变，不需要 isDestroyed 标志。

7 · 绘制层：双缓冲与图层顺序

渲染只读状态，不改写逻辑；顺序表就是 z-index。

  • 两套坐标：逻辑（移动 / 碰撞 / 反弹）只用场地坐标 0~744 / 528；只有 Draw* 里才 + ARENA_X/Y 变成屏幕坐标。
  • 旋转不用世界变换：每个零件在车体坐标系里用 OrientedPoint 算一次，车头朝哪都画得出同一个俯视坦克。

8 · 局域网联机：主机权威 + 全量快照

只有主机跑游戏逻辑，客户端只上报按键、照着主机画面渲染；TCP 非阻塞 + 20 字节帧头。

帧头 20 字节magic「TBGP」/ version / type / 载荷长度 / session / round，全部网络字节序；不用结构体 memcpy，避免对齐填充。
session / round防止上一局残留数据串场：session 不匹配断线；只有 START 能让 round 前进，重赛时旧快照旧输入一律拒收。
held / pressedheld 用于移动转向，pressed 用于开火 / 放雷 / 砌砖的边沿；主机 remotePressed |= pressed 锁存，写成 = 会丢按键。
全量快照地图、砖血、坦克、子弹、激光、追踪弹、地雷、道具、粒子一个不落；客户端只接受 tick 更新的快照，避免画面倒带。

9 · 附录：常见现象 → 多半是哪里

文档第 11 节自查表的精简版，改代码时对着看最快。

现象多半是
坦克穿墙 / 离墙 1px 卡住BoxHitsWall 的 -0.001f 被删了，或速度 × dt 超过半格宽
子弹穿墙 / 斜撞墙方向不对steps 写成固定 1；X、Y 没分开判；漏了 stepx = -stepx
贴墙开炮子弹消失grace 太小，或出生点被推进墙里
激光不折射 / 开炮就自伤LASER_BOUNCE = 0，或撞的是砖墙（吸收不反射）；traveled > 30 保护被删
追踪弹永远打中飞行分支里误加了 BoxHitsWall
砌完砖自己动不了没调 PushOutOfBrick，或 12px 预算不够
画面闪烁 / 中文字方块 / 高分屏模糊没走内存 DC；编译没加 /utf-8；没调 SetProcessDPIAware()
拖窗口后连环快进dt 上限或 NET_MAX_TICK_CATCHUP 太大，累加器没清零
客户端「按了没反应」/ 画面倒带remotePressed |= 写成 =；快照没按 tick > lastSnapshotTick 过滤
重赛后状态错乱 / 连上秒断round 校验被删；帧头 magic / 版本号被改、两边程序版本不同
